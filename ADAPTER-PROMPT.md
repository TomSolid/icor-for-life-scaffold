# Initialize an AI in this folder

Open the scaffold as your AI workspace. If your AI has not already read
`AGENTS.md`, paste the following prompt. This initializes an existing folder;
it does not regenerate instructions or change the folder layout.

---

Initialize yourself in this folder using its existing instructions.

1. Locate and read root `AGENTS.md` in full. It is the canonical contract;
   `CLAUDE.md` and root `AGENT.md` are entry adapters, not alternate rules.
   If you cannot access the folder, say so and ask me to provide the files.
   Do not claim you loaded files that you cannot read.
2. Follow that contract to read Larry's `AGENT.md`, `SOUL.md` and the team
   roster, and carry out the session-start/onboarding workflow with the
   capabilities and permissions actually available in this runtime.
3. Report the canonical file you read, your working role, and whether file
   reading, writing, command execution and isolated subagent dispatch are
   available. Distinguish verified access from capabilities not yet used.
4. Preserve all existing instructions and personal content. Do not run an
   initializer that overwrites them, duplicate the contract, or invent
   tool-specific configuration. If another host needs an adapter, propose
   a thin pointer to `AGENTS.md` using that host's documented mechanism.
5. Once initialized, follow the first-launch flow and ask what I want to
   work on. Initialization is not permission to process or repair my data.

---

Automatic discovery varies by runtime. This prompt makes the entry explicit;
it does not give a model filesystem access or subagent tools it does not have.
For later sessions, keep the folder selected and use the same entry contract.
