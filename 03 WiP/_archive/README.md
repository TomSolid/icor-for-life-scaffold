# _archive

Finished work. When a piece of work is done and its results have moved
to their homes, the working folder moves in here and stops cluttering
the workbench. Nothing is deleted and nothing is renamed.

The archive keeps the same buckets as the room above it, so work keeps
the path it had:

```
_archive/
  Operations/2026-09-18-insurance-renewal.md
  AI Team/2026-09-19-rewrite-sop-1002/
  Projects/Spain Holidays/
  Workstreams/WeeklyReview/2026-09-18-weekly-review/
```

Two rules worth knowing:

- **Move the results out first.** Anything that is knowledge belongs in
  `04 Inner World/`. What stays here is the working record, not the
  answer ([[SOP-1006-start-work-and-archive-a-wip-folder|SOP-1006]]
  step 4).
- **Nothing is archived silently.** Work that has sat untouched for 30
  days is raised in the weekly review and you decide
  ([[WS-1002-weekly-review|WS-1002]]).

The underscore in the name keeps this folder at the top of the file
list and tells every script to skip it.
